# Josiah's Computer Parts Store
This project is a online store of a compomputer parts store where we will sell important parts for a custom made computer for free.
There will be a Customer, and Manager screen as well as a reports screen.

## Detailed Description 

Continuing from the destription this online store will have an easy to navigate customer window as well 
as an easy to work with manager window to manage inventory.

The scope of this project is of course an online store. Included would be a login window, customer,and manager window, as well as a report manager
Some speculated limitations of this project would include the lack of the ability to save a cart post exiting the application, or being able to compare different
products side be side sadly
### Inventory and Inventory Control

My plan on products is computer hardware. For example Cpus,Ram,Fans,Power supplies,Casings, anything that is hardware i plan to include.
My idea on inventory is limiting avalible stock to just 20 per day per item.

The customer will be able to buy a variety of items listed above
