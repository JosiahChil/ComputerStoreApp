This group of components includes a rich text box. a picture box, a label, 2 button, and a combo box. The picture box will show a bigger picture of the item you click from the list of items on the left. The rich text will show a description for the item while the labal should the maximum order amount. The "Add to cart" button allows you to add your item to the card and the "Proceed to checkout" button allows you to go to the checkout form. Lastly the combo box allows you to select an amount of the items to buy
